# WiFiToggle18

A simple Control Center Wi-Fi toggle for iOS 18.

## Features

- Simple Wi-Fi toggle for users who stayed on iOS 18
- Designed for jailbroken iOS 18 devices
- Integrates directly into Control Center
- Lightweight and minimal

## Build

Build with Theos:

```sh
gmake package FINALPACKAGE=1
```
